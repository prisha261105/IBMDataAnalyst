<H1> ABOUT THIS PROJECT</H1>


<H3> As a part of the 5th course, "Python Project for Data Science" , I worked on a real life data set and completed a project that demonstrates how to extract, clean, and visualize real-world stock and revenue data using Python.
It focuses on Tesla and GameStop, showcasing how to combine API data with web scraping to create clear, interactive visualizations for decision-making.</H3>

<b>Data Extraction:</b>
Fetch historical stock prices using yfinance.
Scrape revenue data directly from the web using BeautifulSoup and requests.

<b>Data Wrangling:</b>
Process, clean, and merge datasets with pandas.

<b>Data Visualization:</b>
Create interactive time series charts using plotly.

<b>Reusable Function:</b>
The notebook includes a flexible function to plot stock prices alongside revenue data.

<H4>Libraries Used</H4>
yfinance – to download stock data.
<br>requests – to send HTTP requests.</br>
bs4 (BeautifulSoup) – to parse HTML and extract tables.
<br>pandas – for data cleaning and manipulation.
plotly – for beautiful interactive plots.</br>
