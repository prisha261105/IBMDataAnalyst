# IBMDataAnalyst
I recently completed the IBM Data Analyst course on Coursera. This comprehensive set of 11 courses focused of the basic and intermediary skills that are crucial for any aspiring data analyst including Excel, SQL, Relational Databases, Python, Jupyter Notebooks,Cognos Analytics and more. 
This repository covers all the assignments and projects I attempted while completing this course.
As a part of the 5th course, "Python Project for Data Science" , I worked on a real project where i performed web scraping, data cleaning and analysis and built  a dashboard to compare the stock prices of two companies.
